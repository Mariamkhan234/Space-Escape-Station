# Space Escape Station 🚀

## Project Description
Space Escape Station is a console-based C++ adventure and puzzle game developed as a Data Structures and Algorithms (DSA) project.

The player explores different rooms of a space station, completes missions, collects important items, solves puzzles, and tries to escape successfully.

## Data Structures Used
This project uses the following data structures:

- **Binary Tree:** Represents the rooms and their connections.
- **Stack:** Allows the player to return to previously visited rooms.
- **Queue:** Manages the missions in order.
- **Linked List:** Stores the player's inventory.
- **Vector:** Keeps track of visited rooms.

## Game Features
- Explore different rooms of the space station.
- Solve puzzles to collect important items.
- Complete missions to unlock the escape pod.
- View inventory and pending missions.
- Earn points by completing tasks.
- Experience success or failure depending on mission completion.

## Programming Language
C++

## How to Run
1. Download or clone this repository.
2. Open the `.cpp` file in a C++ IDE.
3. Compile and run the program.
4. Follow the on-screen instructions to play.
